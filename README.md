# Second Brain (app)

Pagina web per scrivere e leggere le note di un vault personale tenuto in un repository GitHub privato.

- Questo repository contiene solo il codice dell'app: nessuna nota, nessun dato, nessuna chiave.
- La chiave d'accesso viene chiesta al primo avvio e resta nel browser del dispositivo.
- La pagina comunica soltanto con `api.github.com` e non carica codice esterno.
- Le note nuove vengono salvate in `00 Inbox`, gli allegati in `_allegati`.
